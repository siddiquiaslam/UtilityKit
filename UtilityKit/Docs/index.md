# UtilityKit

UtilityKit is a lightweight, extensible collection of helper classes and extension methods for .NET (C#). It provides focused utilities for common tasks such as date/time handling, string and collection helpers, argument guards, serialization helpers, and other repeatable patterns so you can write clearer, smaller code without reimplementing the same small utilities.

Use this documentation site to learn how to install and use UtilityKit, read conceptual guides and recipes, and browse the generated API reference.

## Quick install

Install the latest stable package from NuGet:

```bash
dotnet add package UtilityKit
```

Or add a PackageReference:

```xml
<PackageReference Include="UtilityKit" Version="x.y.z" />
```

Replace `x.y.z` with the specific version you want to use.

## Highlights

- Small, composable helpers that follow .NET conventions
- Extension methods for common types to keep call sites expressive
- Guard and validation helpers to reduce repetitive argument checks
- Serialization and JSON convenience wrappers
- Collection and LINQ-style helpers like `DistinctBy`, paging helpers, etc.
- Minimal dependencies — designed to be easy to adopt

## Typical usage

A few example snippets showing common patterns:

```csharp
using UtilityKit;

// Trim or normalize strings
var name = StringHelpers.TrimOrNull("  Alice  "); // "Alice"

// Guard helpers
Guard.NotNull(user, nameof(user));

// Collection helpers
var unique = users.DistinctBy(u => u.Email).ToList();

// Serialization
var json = JsonHelpers.Serialize(user);
var user2 = JsonHelpers.Deserialize<User>(json);
```

See the API reference for exact type and member names for the version you use.
